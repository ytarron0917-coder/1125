🔌 免費數據通道設定（零 CORS）
方案 A（最推薦・永久免費不限流）：Google Apps Script 專屬 API
  1. 打開 script.google.com → 點「新增專案」→ 刪除原本文字，點下方按鈕複製腳本並貼上。
  2. 點右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
  3. 「執行身分」選「我」，「誰可以存取」選「所有人」→ 點部署並授權。
  4. 複製產生的 https://script.google.com/macros/s/.../exec 網址貼在下方即可永久直連！
